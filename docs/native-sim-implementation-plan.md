NAT-01/02 extend the private local gateway and authenticated native workspace API.
Only public workspace selection/layout/focus metadata is stored under the gateway's
workspace profile. Run selection does not change CLI active context. Configuration
changes are proposals until the host publishes them through the existing exact-diff
workflow; fresh plan, cost, independent review and protected approval remain required.

The native architecture page reads `canvas_source.capture` and reuses Sim's actual
`WorkflowBlockView` and `WorkflowEdgeView` within the original workspace sidebar.
Admitted icon bytes come from the existing digest-checked catalog. Declared source,
qualified saved-plan evidence and observed execution stay distinct. Empty runs stay
empty; missing plan/cost/runtime evidence stays UNKNOWN.

Verify adapters with disposable run files and synthetic provider transports. Verify
the native browser on the new compiled image using a separate validation workspace;
source hashes must remain unchanged after inspection, layout and proposal review.
The existing user's provider credentials and working Chat must be preserved.
